  • k6
  • axe-core

A production-style E2E suite against SauceDemo, extended with an AI-driven workflow: agents explore pages through Playwright MCP and draft Page Objects and specs, and a triage script turns failures into Jira-ready bug reports. Cross-browser, mobile emulation, accessibility, network resilience, performance budgets and Slack reporting.

  1. Explore

    Claude Code drives a real browser via Playwright MCP and writes a page map.

  2. Generate

    Drafts a Page Object and spec in the repo's conventions, then runs lint, typecheck and the new test.

  3. Run

    Chromium, Firefox, WebKit and mobile projects in CI, with a11y and performance gates.

  4. Triage

    Failures are merged across browsers, classified, ranked by severity and written as Jira-ready drafts.
